# 🧠 Interactive Quiz App

An interactive quiz application built with React and Vite, featuring shuffled questions, instant feedback, a persistent scoreboard, and the ability to add your own custom questions.

## Features

- Randomized question order on every attempt
- Instant feedback after each answer selection
- Live score tracking through the quiz
- Add your own custom questions, saved to local storage
- Scoreboard that persists past attempts (score, total, date) via local storage
- Clean, minimal UI built with plain CSS

## Tech Stack

- React
- Vite
- JavaScript (ES6+)
- Browser Local Storage

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/kaushal123-git/react-quiz-app.git
cd react-quiz-app
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to use the app.
